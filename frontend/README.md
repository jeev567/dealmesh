# DealMesh frontend

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Visit http://localhost:5173.

## Current scope

v0.1 is an interactive, front-end-only demonstration. Seller profiles, offers, and negotiation messages are fictional sample data. No OpenAI calls, backend, real accounts, or PayPal transactions are connected. Future milestones will implement those features with explicit approvals and server-side validation.
